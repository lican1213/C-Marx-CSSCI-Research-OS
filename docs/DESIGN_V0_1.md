# 马克思主义研究知识库——架构设计 V0.1

状态：候选方案，供用户筛选。日期：2026-11-10。当前仅运行最小化在线验证，不代表完整语料已建成。

## 1. 产品定位

交付对象是可下载、可迁移、长期维护的中文马克思主义研究资料库与本地 Agent 知识基础，而不是一次性聊天机器人。主要使用者为研究者、博士生及学术写作者。要求：离线资料可读；检索可复现；结论可回到具体作品、版本和章节；不同立场/时期的解释不得被强行合并。

非目标：不自动替作者编写没有证据的经典引文；不声称未核验的中文译文可以用作出版引用；不在公开仓库批量镜像版权未明的全集。

## 2. 三种部署路线，建议先 A 再按需 B

| 路线 | 基础 | 功能 | 优点 | 代价/约束 |
|---|---|---|---|---|
| A 轻量知识库（本原型） | 原始文件目录+Markdown Wiki+清单+Python 检索及校验 | 中文概念搜索、证据链、目录、审计、Git 版本化 | 不依赖云模型和数据库即可读、可查、可迁移 | 当前不具备语义问答；中文搜索仍需评测 |
| B LLM Wiki 本地 Agent（推荐下一阶段） | A 的 Markdown+praneybehl/llm-wiki-plugin 或 ddsyasas/llm-wiki | ingest/query/lint、页面重构、跨引用、可选本地 Ollama | 复用成熟项目、Agent 中立、可持续维护 | 需要模型运行时；两个实现不能未经验证混合数据格式 |
| C 重型 RAG | RAGFlow / MaxKB / GraphRAG 等 | 大规模 PDF 表格 OCR、多轮问答与服务化 | 文档密集时能力更强 | 部署、索引、迁移复杂；不适合第一步 |

本轮只证明路线 A 可运行；B/C 为决策候选，绝不宣称已部署或压测。

## 3. 知识范围：领域树与时间层

L0 元信息：书目、作者、写作/发表年代、版本/译者、权利与可靠度。
L1 原始作品：马克思恩格斯、列宁等经典文本目录，按作品—篇章—段落定位。
L2 理论概念：历史唯物主义、辩证法、实践、生产力与生产关系、剩余价值、阶级等。
L3 历史发展：中国化时代化理论、不同历史时期文本与政策文本，应保留时间、语境、来源。
L4 学术研究：中文 CSSCI、英文同行评审论文、理论争议、研究方法、规范引文。
L5 研究输出：文献综述提纲、比较表、研究问题卡、论证链与待验证问题。

**边界**：区分原作者主张、后人阐释、学界争议与 Agent 推论；当材料不能支持结论时应返回“证据不足”。

## 4. 文件与数据契约

README.md / AGENTS.md / SCHEMA.md / MOC.md
raw/              原始获授权文件；默认不对外包含受限全文
catalog/sources.jsonl  每条一作品或版本，来源与授权状态不可省
catalog/claims.jsonl   一条可检验命题对应一处原始来源和定位
wiki/concepts/    概念卡；内容为原创摘要，不冒充作者原话
wiki/works/       作品与版本说明卡
wiki/synthesis/   主题比较、理论路径与争议卡
wiki/index.md     人类和 Agent 的入口
scripts/kb.py     轻量检索和结构审计
tests/            可重复自动化验证
docs/             设计、来源政策、审计证据和筛选记录

核心标识：
- source_id：稳定、不随文件名变化；尽量一个“作品×版本/译本”一条，避免混版页码。
- claim_id：某一明确观点与文献定位的链接，不等于可以直接引用的逐字引文。
- locator：章节/段落/页码及其 edition；未实测页码不能填猜测页码。
- rights_status：public_domain_us / permission_needed / catalog_only / license_verified 等，不能默认 GitHub 公开就可再发布。
- verification：metadata_checked / text_checked / page_checked 等，分别报告。

## 5. 语料进入工作流

发现来源 → 核对书目版本与许可 → 保存 source_id、URL、检查时间 →（获许可才导入全文）文本抽取→ OCR/繁简/编码校验 → 结构化切分 → 段落 ID、章节标题与页码映射 → 精确引用核验 → 概念提取 → 写入 Wiki 及 claims → 反向链接 → 检索测试 → 对抗式审计。

切分规则：章节/小节优先，段落次之；保留原始段落顺序、标题、脚注和来源偏移；不把不同篇章拼成一个无法引用的块。大型 PDF 需人工抽查跨页、脚注和公式。原文、OCR 转写、中文译文、模型摘要严格分离。

## 6. 中文学术语言约束

默认简体中文，理论术语优先用标准学术译名，保留德文/英文等原语及别名；不将原始语境中的“阶级”“国家”“社会形态”机械替换成现代术语。坚持“问题—文本依据—解释—争议/边界”写法。引号内只放已核验的原文；译者、年份、卷次、页码有不确定性就明确缺项。中文破折号使用“——”（连续两个 U+2014）。

## 7. 检索与问答

第一阶段：中文字符 n-gram + 英文 token 的确定性检索，优先命中作品/概念、原始出处链接和定位，不生成 AI 答案。
第二阶段：BM25 + 合适的中文/多语语义模型 + 可选重排 + 证据链；对事实问答按用户问题溯回原文。
第三阶段：研究 Agent 实现“检索→检查原段→提出有限结论→列出引文信息→反例查找→输出”。学术引文必须核对指定出版版本，不允许将网页章节定位伪装成原书页码。

## 8. 必过质量门（Gate）

G0 法律/版本：不得把来源许可未知的整卷原文公开提交。
G1 基础结构：来源和命题 ID 唯一、元数据齐全、文件 UTF-8、有效链接。
G2 溯源：每张概念卡至少引用一条可定位命题，每条命题有真实来源链接和章节。
G3 中文检索：事先固定的术语、别名和概念组合测试不得出现空证据或明显错排；无关问题应返回零命中。
G4 矛盾/时序：两作者/不同时期/译本差异不被模型自行消解；以卡片分层记录。
G5 引文可靠性：随机抽查原文和指定出版版一致后才标记为可直接引用。
G6 可移植性：不需密钥、不需在线数据库即可阅读 Wiki 和运行轻量检索。
G7 回归与篡改：故意删除 source_id、破坏 Wiki 链接、重复 claim_id、填造页码等测试应失败。

## 9. 完成度定义

POC（本轮目标）：目录、小规模来源和命题索引、原创中文概念卡、可用 CLI、自动 Gate、在线试验分支。
MVP：已明确允许使用的语料按原始著作/章节完成抽取、检索；不少于 100 个经查核概念/作品卡，盲测集含至少 50 个真实查询及 20 个错误引文/无答案陷阱。
正式研究版：真实出版版本信息、校勘或页码对照、CSSCI 文献引文审计、人审的领域专家错例复盘、完整版权清单、本地大模型 Agent 端到端验证。

POC/MVP 阈值是拟议验收标准，不是已完成的成绩。
